# DocuMind Summarizer 

**DocuMind Summarizer** is a modern, client-side web application designed to instantly transform long PDF documents, transscripts, reports, and study notes into structured, visual summaries, executive highlights, and key takeaways using browser-based text parsing.

---

##  Features

* **Instant PDF Parsing:** Powered by **PDF.js** to extract text from multi-page documents seamlessly right in your browser.
* **Executive Summary:** Automatically generates high-level summaries of uploaded documents.
* **Key Insights & Takeaways:** Breaks down complex text blocks into digestible, structured visual cards.
* **Document Outline View:** Organizes document structure page-by-page.
* **History Sidebar:** Seamlessly switch between previously uploaded documents without losing context.
* **100% Client-Side:** No backend server or heavy API keys required; runs entirely and securely in your browser.

---

## 🛠️ Built With

* **HTML5 & CSS3** (Modern responsive layout with CSS Grid/Flexbox)
* **JavaScript (ES6+)** (Core logic & DOM manipulation)
* **PDF.js** (Mozilla's robust PDF parsing library)
* **Tesseract.js** (OCR fallback support for scanned PDFs)
